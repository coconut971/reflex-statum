# Distribution de Reflex Statum

Jeu développé par FCC. Ce dépôt contient les téléchargements Windows, un prototype Web compilé et leur documentation.

Le téléchargement et l’installation incluent les bibliothèques redistribuées avec leurs licences. Vous trouverez les mentions et textes correspondants dans `THIRD_PARTY.md`, le dossier `licenses` et `assets/fonts/OFL.txt` à côté du programme installé.

La présence d’un dépôt de téléchargement public ne publie pas le code source du jeu sous une licence libre.
